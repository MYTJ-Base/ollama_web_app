💬 MESSAGE FLOW (What Happens When You Chat)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  You type:  "What is Python?"
              ↓↓↓
  Browser:   Sends HTTP POST request to backend
              ↓↓↓
  Backend:   Receives request, parses JSON
              ↓↓↓
  Backend:   Sends HTTP POST request to Ollama
              ↓↓↓
  Ollama:    Processes with Qwen model
              ↓↓↓
  Ollama:    Returns response as JSON
              ↓↓↓
  Backend:   Receives response from Ollama
              ↓↓↓
  Backend:   Sends response back to browser as JSON
              ↓↓↓
  Browser:   Displays: "Python is a programming language..."
              ✨ Done!


🎯 KEY CONCEPTS YOU'LL LEARN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PORT 🚪
  └─ Virtual "door" for services: 5000 (backend), 11434 (Ollama)

  API 📋
  └─ Rules for how programs talk: GET, POST, endpoints, responses

  REQUEST ➡️
  └─ Message FROM frontend TO backend (what user sends)

  RESPONSE ⬅️
  └─ Message FROM backend TO frontend (what user receives)

  JSON 📦
  └─ Data format: {"key": "value"} - used in all requests/responses

  HTTP METHODS 🎯
  └─ GET (request data), POST (send data with body)

  ENDPOINT 🛣️
  └─ Specific path: /api/chat, /api/health, /

⚙️ WHAT HAPPENS WHEN YOU RUN IT
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. Python backend starts on port 5000
     ✓ Flask loads
     ✓ Routes defined
     ✓ Ready to receive requests

  2. Browser opens http://localhost:5000
     ✓ Backend sends HTML file
     ✓ Browser displays chat interface
     ✓ JavaScript loaded and waiting for input

  3. You type a message and click Send
     ✓ JavaScript creates fetch() request
     ✓ Sends to http://localhost:5000/api/chat
     ✓ Backend receives it

  4. Backend processes and sends to Ollama
     ✓ Makes HTTP request to port 11434
     ✓ Ollama processes with Qwen model
     ✓ Returns response

  5. Response flows back to you
     ✓ Backend receives from Ollama
     ✓ Backend sends to browser
     ✓ JavaScript displays in chat


🆘 SOMETHING NOT WORKING?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  "Cannot connect to Ollama"
  → Make sure Terminal 1 has "ollama serve" running
  → Run: ollama pull qwen  (if not already done)


  "Port 5000 already in use"
  → Change FLASK_PORT = 8000 in backend.py
  → Or restart your computer


  "Frontend won't load"
  → Make sure backend is running and says "running on..."
  → Wait 5 seconds for server to fully start
  → Try http://localhost:5000 (exact address)


  "Responses are slow"
  → Normal! First response loads the model (30-60 seconds)
  → Subsequent responses are much faster
